## 📦 Run or Modify Locally

Because this application is built 100% using static client-side web technology, you can completely customize it on your own machine!

1. Click the green **Code** button at the top of this repository.
2. Select **Download ZIP**.
3. Extract the contents onto your laptop.
4. Open up `index.html` in a text editor (like VS Code or Notepad) to change the wallet balances, pricing multiplier taxes, or token thresholds.
5. Double-click `index.html` to run your personalized SaaS marketplace completely offline!
